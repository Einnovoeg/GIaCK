# GIACK GPTK 1.0

Release date: August 18, 2026  
Bundle version: 1

GIACK GPTK 1.0 is the first public release of this maintained macOS fork. It provides a cohesive native interface for GPTK Wine bottles and DOSBox Staging libraries while preserving the GPL-3.0-or-later obligations of its upstream work.

## Highlights

- Create Windows and DOS libraries from compatibility presets.
- Choose a managed GPTK runtime or supported Homebrew Wine channel.
- Check runner status, Rosetta, Homebrew, DOSBox, and runtime health in Settings.
- See the active Wine runtime in the main library sidebar.
- Use `GIACKCmd` to list or create libraries with the same preset model as the GUI.
- Benefit from tooltip coverage across interactive controls.

## Important Notes

- This release is unsigned and not notarized.
- GPTK, Wine, DOSBox Staging, and Winetricks dependencies are not bundled in the repository.
- Compatibility is application-specific. Collect the selected runner, runtime version, and relevant logs when reporting a problem.
- Per-bottle Wine runtime selection and game-specific installer manifests remain future work.

Please report reproducible issues and contribute fixes, compatibility findings, documentation improvements, or tests where possible.
